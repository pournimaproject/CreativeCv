# Pournima Pote's Portfolio Website

A playful and interactive portfolio website with advanced CSS animations and theme toggle inspired by Cassie Codes.

## Features

- Interactive lamp for theme toggle (dark/light mode)
- Advanced CSS animations and effects
- Responsive design for all devices
- Project showcase section
- Articles section
- About section
- Easter egg feature (Konami code: ↑↑↓↓←→←→BA)

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Express.js
- Shadcn UI Components

## Local Development

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

## Production Build

```bash
# Create a production build
npm run build

# Start the production server
npm start
```

## Deployment Instructions

This project is configured for deployment on Render.com.
